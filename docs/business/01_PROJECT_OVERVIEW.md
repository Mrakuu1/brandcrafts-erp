# BrandCrafts ERP (MVP)

## Project Overview

BrandCrafts ERP is a modern Android-based Enterprise Resource Planning (ERP) application developed exclusively for BrandCrafts.

The application is designed to digitize and simplify the company's day-to-day operations including inventory management, stock movement, quotations, purchase orders, billing, delivery challans, customer management, supplier management, and employee access control.

The primary objective is to replace manual record keeping with a lightweight, mobile-first ERP that is fast, easy to use, and scalable for future enhancements.

# User Roles

## Admin

Complete control over the application.

Can:

- Manage inventory
- Manage customers
- Manage suppliers
- Manage quotations
- Manage purchase orders
- Generate invoices
- Generate delivery challans
- Manage employees
- Configure application settings
- View business reports

---

## Employee

Operational access only.

Can:

- View inventory
- Perform stock movement
- Record material usage
- Create quotations
- Generate invoices
- Create delivery challans
- View customers
- View suppliers

Employees cannot access administrative functions.

# Project Scope

The MVP focuses on replacing manual operations with a simple mobile workflow.

Complex ERP functionality such as payroll, HR, attendance, production planning, accounting, GST filing, and purchase automation are outside the scope of this version.
